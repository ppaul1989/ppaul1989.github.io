# KaucjoPortfel developer website

Static GitHub Pages user site at https://ppaul1989.github.io/.

- Homepage: `/index.html`
- Android privacy policy: `/kaucjoportfel/privacy.html`
- AdMob authorized seller record: `/app-ads.txt` (must stay at domain root)
- Shared styling: `/style.css`

GitHub Pages publishes the `main` branch root. `.nojekyll` serves the files directly.
No dependencies, tracking scripts, external fonts, build step or server are required.

The policy describes the currently distributed offline Android build. Update it and
the Play disclosures when adding the Ads/UMP SDK, rather than claiming future SDK
behavior is already present. Never publish private keys or account credentials here.
